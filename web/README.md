# MemoIsle Web

## 运行

先启动仓库中的后端服务，再执行：

```bash
cd web
npm install
npm run dev
```

开发服务器会将 `/api` 代理到 `http://127.0.0.1:8000`。部署时可通过
`VITE_API_BASE_URL` 指向实际的 `/api/v1` 地址。端口被启动器改到 5174/8011 之类
的地址也不影响扩展：页面会把当前源与 API 地址告诉扩展，扩展按这个地址回连。

## 当前功能

- 创建、搜索和整理灵感、网页资料、英语单词与图片。
- 图片收藏工作区支持选择、拖拽或 `Ctrl/⌘+V` 粘贴上传，以认证缩略图网格展示，并支持查看原图、下载、替换和编辑标题备注。
- 图片超过 20 MB、单边 12000 像素或 5000 万像素时先自动压缩/缩放（优先 WebP）再上传，并在上传列表和全局提示里告知压缩前后的大小与尺寸/格式变化。
- 使用 `@网页` 选择浏览器当前打开的网页。
- 顶部提供浏览器扩展 ZIP 下载入口；导入备份、导入单词和三种导出收进「数据」菜单。
- 首页和网页资料页的「快速访问」按打开次数列出常用网页，可移除并撤销，移除后可在预览里重新显示；网页资料可按「最常打开」排序。
- 网页资料预览可直接编辑标题、网址、备注和标签；分类模板分「分类」「自动规则」两页管理。
- 键盘快捷键：`/` 搜索、`N` 新建；网页资料列表 `J`/`K` 移动、`Enter` 预览、`E` 编辑、`O` 打开原网页、`C` 复制链接、`S` 星标、`X` 选中、`Delete` 移入回收站、`[`/`]` 翻页；按 `?` 查看全部。
- 导入 Chrome 书签并自动分类网页资料。
- 网页大模型分类支持临时故障自动重试、等待进度和具体错误提示；「继续任务」保留原队列，已处理条目不会重复请求。可用「重新分类已完成」把已完成的模型分类再跑一轮。
- 网页分类结合公开正文摘要和完整模板路径；列表和详情展示大模型列出的标签或自动标签，详情可查看置信度、候选类别概率、未确定原因和当次摘要，低置信度保留原分类。
- 「网页资料 → 智能生成分类」先确认顶级分类是否够用，够用后再细分，不够则先补顶级分类。整理要求可留空。细类按网页用途命名；模型不可用时也按用途聚类，不用网站名。结果直接显示在页面上并会保留。加入模板后再重新分类即可写到网页上。
- 「网页资料 → 分类确认」按每页 50 条复核模型未确定的网页，可按标题、网址、未确定原因、首选候选和最高置信度筛选，批量采纳所选候选、指定分类或保留原分类。也可把全部待确认网页重新交给大模型和 Jev 分类。人工确认后停止自动分类；确认失效的网页不进入分类确认。
- 编辑内容并使用版本号检测跨设备更新冲突。
- 回收站支持「一键还原」和「一键清空」，操作覆盖全部回收站内容，不受搜索或当前显示条数限制；清空前确认永久删除。
- 内容列表和回收站支持每页 10/25/50/100 条、全选当前页与取消选择；选中移入回收站、还原选中和永久删除选中只处理明确选择的版本，分页或筛选会清除选择，冲突逐项反馈。
- 图片批量整理可对全部未处理或选中图片执行本地 PyTorch OCR，并用 Jev 按现有模板归类；可查看进度和继续失败任务，已处理和人工分类跳过。无文字或判断未确定时保留原分类，详情可手动选择模板，列表可按分类筛选。
- 重复图片按完整文件哈希分组，大组及组内均可分页；选中记录移入回收站并可还原，不自动删除。
- 响应式桌面和移动布局。
