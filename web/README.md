# MemoIsle Web

## 运行

先启动仓库中的后端服务，再执行：

```bash
cd web
npm install
npm run dev
```

开发服务器会将 `/api` 代理到 `http://127.0.0.1:8000`。部署时可通过
`VITE_API_BASE_URL` 指向实际的 `/api/v1` 地址。

## 当前功能

- 创建、搜索和整理灵感、网页资料与英语单词。
- 使用 `@网页` 选择浏览器当前打开的网页。
- 顶部提供浏览器扩展 ZIP 下载入口。
- 导入 Chrome 书签并自动分类网页资料。
- 编辑内容并使用版本号检测跨设备更新冲突。
- 响应式桌面和移动布局。
