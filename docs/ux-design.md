# MemoIsle 交互与页面设计

## 1. 设计原则

- 捕获优先：新建入口始终可达，先保存再整理。
- 内容优先：详情页首先呈现用户保存的内容，属性作为辅助。
- 一致但不僵化：三种内容共享布局骨架，同时保留各自的专用动作。
- 原始内容可信：语音转写可编辑，但原始录音始终保留；自动建议必须可识别和撤销。
- 状态透明：保存、上传、转写、同步和失败状态不可隐藏。
- 私人空间感：界面克制、安静，避免社交平台式的信息噪声。

## 2. 信息架构

### 2.1 Web

```text
MemoIsle
├── 首页
│   ├── 快速捕获
│   ├── 今日回顾
│   └── 最近内容
├── 收件箱
├── 资料库
│   ├── 全部
│   ├── 单词
│   ├── 网页资料
│   └── 灵感
├── 回顾
│   ├── 单词复习
│   ├── 待阅读
│   └── 待整理灵感
├── 收藏夹
├── 标签
└── 设置
    ├── 账号与同步
    ├── 导入与导出
    ├── 录音与转写
    └── 隐私与数据
```

Web 采用固定左侧栏、顶部全局搜索、主内容区和按需出现的右侧详情面板。网页资料不使用右侧详情面板，分类和星标直接在最近内容列表修改；灵感与单词仍可打开侧栏编辑。

### 2.2 Android

底部导航使用四个稳定入口：

- 首页：今日回顾、最近内容和同步提示。
- 资料库：搜索、筛选和三类内容列表。
- 回顾：单词、资料和灵感队列。
- 我的：账号、存储、导出、权限和设置。

全局新建按钮悬浮在底部导航上方或位于导航中央，点击后展开“单词、灵感、语音”三个动作。网页资料主要在 Web 创建和整理；Android 通过系统分享轻量保存链接，保存后进入只读详情，不强制跳转首页。

## 3. 核心用户流程

### 3.1 快速捕获

```text
点击新建 / 接收系统分享
  → 选择类型或输入内容
  → 系统建议类型与基础元数据
  → 用户确认或补充
  → 立即保存
  → 后台执行元数据抓取、自动分类、上传或转写
  → 成功反馈，可继续编辑
```

Android 网页资料是例外：系统分享仅允许在保存前确认最小信息，保存后只可浏览、搜索、复制和打开原链接，后续编辑统一在 Web 完成。

网页资料保存时不显示必选分类控件。保存后先在列表显示“分类中”，任务完成后替换为系统分类；Web 直接在列表纠正分类和切换星标，Android 只读展示。

当后台任务失败时，条目仍然存在，只将对应能力标记为失败并提供重试。

### 3.2 语音灵感

```text
点击语音
  → 首次使用时说明并请求麦克风权限
  → 录音中（暂停 / 继续 / 完成）
  → 本地生成可播放草稿
  → 保存条目并排队上传
  → 异步转写
  → 用户校对标题与文本
```

拒绝权限后保留文字输入入口，并在用户再次选择语音时提供“前往设置”。

### 3.3 单词复习

```text
进入今日回顾
  → 展示单词与语境，隐藏释义
  → 用户思考后点击显示答案
  → 选择忘记 / 模糊 / 记得
  → 更新复习计划
  → 下一条或完成摘要
```

### 3.4 搜索与找回

```text
输入关键词
  → 即时显示跨类型结果
  → 网页资料按一个主分类或星标进一步筛选
  → 通过标题、站点、分类和命中摘要确认目标资料
  → 打开详情或原始链接
  → 阅读、复习、编辑，或在 Android 只读资料详情中访问来源
```

资料刚保存但尚未完成元数据与自动分类时，仍可通过用户输入的标题、网址和备注搜索。后台任务完成后结果自动补充站点、分类和描述，不要求用户重新保存。

## 5. 关键页面布局

### 5.1 W-01 Web 首页/资料库工作台

- 左侧固定导航宽约 232 px，底部显示账号和同步状态。
- 顶部为宽搜索框，右侧是“新建”主按钮和头像。
- 主区首行展示简短问候与“今天有 N 条值得回顾”。
- 快速捕获区域是清晰输入框，不使用装饰性大卡片占据首屏。
- 今日回顾使用一张主要卡片呈现下一条内容，并用三个紧凑统计显示单词、待读、待整理数量。
- 最近内容是混合列表，每行显示类型图标、标题、摘要、更新时间和类型化主动作；网页资料额外显示一个分类与星标。
- 网页资料显示自动分类徽标；“分类中”使用中性状态，不阻塞打开资料。
- 网页资料不展示资源类型、阅读进度、标签、收藏夹或资料状态表单，避免重复组织维度。

### 5.2 W-02 Web 快速捕获抽屉

- 从右侧滑入，宽 440 至 520 px，底层页面保持上下文。
- 顶部类型分段控件：单词、资料、灵感。
- 根据粘贴内容给出类型建议，但不自动切换并提交。
- 主输入区足够大；次要字段折叠在“补充信息”。
- 输入 `@` 展开命令菜单，列出当前浏览器各窗口已打开的网页；选择后插入不可误认为普通文本的 `@网页` 附件卡片。
- `@网页` 菜单从输入框下方向下展开，限制可视高度并在菜单内部滚动；长标题和来源单行省略，不能撑出页面或被顶部浏览器区域遮挡。
- `@网页` 标签页快照与资料处理状态采用静默刷新：首次打开可显示加载状态，后续轮询必须保留当前内容，不能反复清空菜单或切换整页加载态。
- 最近内容中的网页资料标题和域名在新标签页打开原网页；每行直接提供一个分类下拉框和星标按钮，点击其他区域不打开资料侧栏。
- 附件卡片显示所选网页标题、域名和网址；之后切换浏览器标签页不静默替换已附加内容。
- 扩展未连接或快照为空时显示“下载扩展”和粘贴网址入口；下载后提示解压并在 Chrome/Edge 中加载。扩展只同步 URL、标题和图标，不读取历史、Cookie、表单或页面正文。
- 底部固定“保存”按钮，旁边提供“保存后打开详情”选项。
- 关闭有未保存内容的抽屉时二次确认。

### 5.3 W-08 Chrome 书签导入

- 从资料库或设置页进入，选择 Chrome 导出的 `.html` 书签文件。
- 文件解析后先展示有效、重复、无效和待导入数量，不在选择文件后立即写入资料库。
- 预览按 Chrome 原文件夹路径分组；文件夹只用于来源追溯，自动分类结果单独显示。
- 用户确认后展示批量进度，允许离开页面；返回后仍可查看导入批次状态。
- 完成页展示成功、跳过和失败数量，提供“查看已导入资料”“重试失败项”和“撤销本次导入”。
- 新导入资料先显示“分类中”，分类完成后可在对应分类筛选中找到。

### 5.4 W-09 浏览器扩展捕获

- 扩展启用后同步当前浏览器各窗口中已打开的 HTTP(S) 网页；标签页创建、更新、切换或关闭时刷新快照。
- 用户在任意网页点击扩展图标、快捷键或右键“收藏到 MemoIsle”时，仍可直接创建短时、一次性的当前页附件并打开 MemoIsle 快速捕获。
- 在 Web 快速捕获中输入 `@` 可从当前浏览器快照选择任意打开网页；选择后出现 `@网页` 卡片，用户可添加备注后保存，也可移除卡片取消。
- Web 顶栏常驻“下载扩展”按钮，未连接提示中重复提供同一下载入口，减少用户寻找项目目录的成本。
- 保存成功后显示自动分类状态和“在资料库查看”，重复网址则展示已有资料入口。
- 扩展断开、快照为空或页面不受支持时保留用户备注，并提供重试或粘贴网址降级入口。

### 5.5 W-10 网页巡检中心

- 资料库侧栏提供系统分组“失效网页”，角标只显示待处理数量，不以高频弹窗打断用户。
- 顶部摘要分别展示确认失效、重定向、信息可更新和暂时失败数量。
- 每条结果显示原网址、最近成功时间、最近检查时间、连续失败次数和判定原因。
- 主操作按状态变化：失效项提供“重试、更新网址、忽略、删除”，重定向项提供“采用新网址”，信息变化项提供“更新资料信息”。
- 支持多选批量重试、忽略或移入回收站；删除前显示影响数量并二次确认。
- 同一站点大面积暂时失败时合并提示，避免为每条资料产生一条通知。
- 默认使用站内汇总提醒；用户可在设置中调整周期或暂停巡检。

### 5.6 A-01 Android 首页

- 顶部包含产品名、搜索和同步状态，不重复使用大型标题。
- 首屏显示今日回顾主卡和四个快速动作。
- 最近内容按时间分组，单列展示，支持横滑星标或归档；删除不使用横滑直接触发。
- 底部导航固定，中央新建按钮与系统手势区域保持安全距离。

### 5.7 A-03 Android 语音记录

- 使用沉浸但不全黑的专注界面，顶部明确标注“语音灵感”。
- 中部显示时长和真实输入音量反馈，不能只播放装饰性动画。
- 主按钮用于暂停/继续，完成与取消具有足够间距。
- 下部提供实时或延迟转写说明；转写不应干扰录音。
- 锁屏、来电、录音中断和权限撤销后提供可恢复状态。

### 5.8 单词复习（跨端）

- 一次只显示一条，顶部展示进度但不制造倒计时压力。
- 正面展示词形、发音入口和保存时的原句。
- 点击“显示答案”后展开释义、例句和个人备注。
- 反馈按钮顺序固定为“忘记、模糊、记得”，颜色不能成为唯一识别方式。

## 6. 通用交互规则

### 6.1 状态反馈

| 状态 | 展示规则 |
| --- | --- |
| 正在保存 | 按钮进入忙碌态，输入保持可见 |
| 已保存 | 轻量提示，并显示可撤销动作 |
| 等待同步 | 条目显示云端等待图标，不阻塞继续编辑 |
| 同步失败 | 条目级错误提示和重试入口 |
| 转写中 | 骨架文本加明确说明，不伪造结果 |
| 转写失败 | 保留播放器，显示失败原因和重试 |
| 分类中 | 显示中性徽标，资料仍可正常打开和搜索 |
| 分类失败 | 自动归入“其他”，Web 最近内容列表提供分类纠正入口 |
| 书签解析失败 | 保留文件选择页，说明格式问题，不创建任何资料 |
| 书签部分导入失败 | 保留成功项，列出失败项并允许单独重试 |
| 扩展未安装/未连接 | Web 提供扩展 ZIP 下载、解压安装指引，并保留粘贴网址入口 |
| 当前页不受支持 | 说明浏览器内部页或协议限制，不创建空资料 |
| 巡检暂时失败 | 显示下次重试时间，不进入失效网页分组 |
| 网页确认失效 | 保留资料内容并进入“失效网页”，提供处理动作 |
| 网页已重定向 | 展示新旧网址，等待用户确认更新 |
| 离线 | 页面级状态条，仅在状态变化时提示 |

### 6.2 空状态

- 首次使用：解释该区域价值，并提供对应新建按钮。
- 筛选无结果：显示当前筛选条件和“清除筛选”。
- 搜索无结果：保留查询词，建议检查拼写或直接创建条目。
- 回顾已完成：展示完成数量和返回资料库入口。

### 6.3 键盘与快捷键

- Web 使用 `/` 聚焦全局搜索，`N` 打开新建，`Esc` 关闭浮层。
- 快捷键在输入框聚焦时不得误触发。
- 所有菜单和分段控件可通过 Tab、方向键和 Enter 操作。

## 7. 响应式与可访问性

- Web 主断点建议：小于 768 px 使用移动布局，768–1179 px 使用折叠侧栏，大于等于 1180 px 使用完整工作台。
- Android 基准设计宽度为 412 dp，同时验证 360 dp 与大字体模式。
- 触控目标至少 44×44 dp，控件间距至少 8 dp。
- 正文最小 14 sp，主要内容建议 16 sp；允许系统字体缩放。
- 颜色之外同时使用文字、图标或形状表达状态。
- 录音波形提供文字时长和状态说明，不能作为唯一反馈。
- 动画尊重减少动态效果设置。
