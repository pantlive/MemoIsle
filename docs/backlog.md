## 4. 待产品确认

不阻塞当前开发，但会决定后续实现方式：

- 语音转写采用设备端、云服务还是自托管 PyTorch 模型。
- 图片 OCR 是否允许把图片发送到第三方视觉模型，以及按账号的 OCR 开关与额度。
- 免费用户的录音时长、存储容量和转写额度。
- 数据存储区域、备份周期与账号注销后的删除时限。
- 词典音频是否升级为授权音源；当前查词预览使用 Free Dictionary API。

已确认：

- 当前账号方式为邮箱密码。微信、Google、Apple ID 登录暂缓。
- 邮箱注册使用六位验证码；密码找回使用一次性链接。
