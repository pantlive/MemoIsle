## 1. 产品定义

MemoIsle 是一个私人优先的知识捕获与回顾工具。用户可以保存英语单词、网页学习资料和临时灵感，通过标签、收藏夹、搜索与回顾机制，在需要时重新找到并使用它们。

一句话价值主张：

> 看到或想到值得保留的东西时，用最少步骤记下来；以后真正找得到、记得住、用得上。

## 2. 为什么三类内容适合放在一起

三类内容都需要快速捕获、补充上下文、分类、跨端同步、搜索和再次使用。统一产品能够降低入口切换和维护成本，并形成完整的个人知识流。

同时，三类内容的后续动作不同：

| 类型 | 捕获重点 | 后续动作 |
| --- | --- | --- |
| 英语单词 | 单词、语境、来源 | 发音、释义、复习 |
| 网页资料 | 链接、标题、来源、备注 | 阅读、归档、再次访问 |
| 灵感 | 原始想法、语音、上下文 | 补充、发展、转为行动 |

因此采用“统一底层模型 + 类型化体验”，而不是三个独立应用，也不是把所有内容都压缩成同一种表单。

## 3. 目标与非目标

### 3.1 MVP 目标

- 任意核心内容在 10 秒内开始保存。
- Web 和 Android 使用同一账号后可看到一致数据。
- 用户能通过关键词、类型、自动分类、标签、收藏夹和状态找到内容。
- 语音灵感保留原始录音，并生成可搜索的文字转写。
- 单词从“收藏”进入“可复习”状态，形成最小学习闭环。
- 网页资料能够从 Android 分享菜单和 Web 粘贴链接快速保存。
- 网页资料以 Web 为主要创建、整理和编辑端；Android 以浏览、搜索和打开原链接为主。

### 3.2 非目标

- MVP 不做公开内容社区、关注或点赞。
- MVP 不做多人实时协作和团队知识库。
- MVP 不抓取或长期保存完整网页正文，仅保存用户输入、链接和合规元数据。
- MVP 不做复杂任务管理、日历或项目管理。
- MVP 不依赖生成式 AI 自动改写用户原始内容。
- MVP 不做 iOS 客户端，但后端和数据模型需避免平台绑定。

## 4. 目标用户与核心场景

### 4.1 目标用户

- 经常在浏览器和手机之间切换的学习者。
- 学英语时希望保存语境并持续复习的人。
- 经常收藏教程、课程、文章、工具和视频的人。
- 需要随时记下灵感，并希望后续能找到的人。

### 4.2 核心场景

1. 用户在网页中遇到生词，保存单词和原句，晚些时候在复习页查看。
2. 用户在 Android 浏览器或应用中发现学习资料，通过系统分享发送到 MemoIsle。
3. 用户走路时产生想法，长按快速入口开始录音，结束后得到录音与转写文本。
4. 用户只记得片段关键词，通过全局搜索同时命中单词、资料和灵感。
5. 用户打开“今日回顾”，继续未读资料、复习到期单词或整理未分类灵感。

## 5. 产品模型

### 5.1 统一条目 Memo

每条内容都是一个 `Memo`，包含通用字段，并根据类型附加扩展字段。

通用字段：

- `id`：全局唯一标识。
- `type`：`word`、`resource`、`idea`。
- `title`：可搜索标题。
- `body`：用户正文或备注。
- `source_url`：可选来源链接。
- `source_title`：可选来源名称。
- `tags`：多个标签。
- `collection_ids`：可加入多个收藏夹。
- `status`：`inbox`、`active`、`archived`、`trashed`。
- `is_favorite`：是否星标。
- `created_at`、`updated_at`：创建与更新时间。

类型扩展：

- 单词：词形、音标、语言、释义、例句、上下文、熟悉度、下次复习时间。
- 网页资料：网址、站点、一个主分类、星标、封面和后台元数据；用户只维护分类与星标两个组织属性。
- 灵感：录音、转写文本、转写状态、灵感阶段。

### 5.2 收件箱

快速保存时允许只填写最少内容。未分类条目进入“收件箱”，用户后续可补充类型、标题、标签或收藏夹。收件箱是状态，不是第四种内容类型。

## 6. 功能需求

优先级定义：P0 为 MVP 必须，P1 为 MVP 后优先，P2 为长期能力。

### FR-01 统一快速捕获（P0）

- Web 顶部和 Android 底部提供全局“新建”入口。
- 用户可选择单词、网页资料或灵感，也可先输入内容再由系统建议类型。
- 系统建议只做辅助，最终类型由用户确认或修改。
- 允许最少字段保存：单词只需词形，资料只需网址，灵感只需文字或录音。
- 保存成功后给出明确反馈，并提供“继续编辑”和“撤销”。
- Android 通过系统分享保存网页资料后进入只读详情，不提供后续编辑入口。
- 重复网址或相同词形出现时提示已有条目，允许查看、合并或仍然保存。

验收标准：

- 从任意一级页面最多一次点击进入快速捕获。
- 网络正常时，提交后 2 秒内出现成功状态。
- 保存失败时保留用户输入，并允许重试。

### FR-02 英语单词收藏与复习（P0）

- 支持输入或粘贴英语单词、短语和原句。
- 支持保存音标、释义、例句、个人备注和来源。
- 提供英式/美式发音播放入口；无音频时需显示不可用状态。
- 单词详情展示最近复习时间、熟悉度和下次复习时间。
- 提供“忘记、模糊、记得”三个复习反馈，更新下次复习时间。
- 默认隐藏答案，用户主动显示释义与例句。
- 相同规范化词形默认视为潜在重复，但不同语境可分别追加为例句。

P1：词形变化归并、自定义复习计划、批量导入导出。

### FR-03 网页资料收藏（P0）

- Web 是网页资料的主要工作台，支持粘贴网址、创建、补充备注和完整编辑。
- Android 注册系统分享目标，接收浏览器或其他应用分享的链接与文本。
- Android 资料库和详情页以只读浏览为主，支持搜索、查看摘要和打开原链接。
- Android 不提供已保存网页资料的标题、网址、备注和状态编辑入口。
- Android 不提供常驻的手动新建资料入口；系统分享保留最小确认与保存流程。
- Web 默认通过 MemoIsle 扩展直接读取当前 Chrome/Edge 的书签树，无需用户导出或上传文件；未安装新版扩展时，保留 Google Chrome 标准书签 HTML 本地解析作为备用方式。
- Web 快速捕获支持 `@` 命令菜单；MemoIsle Chrome 扩展同步当前浏览器各窗口中已打开的可收藏网页，选择任意 `@网页` 后无需复制网址。
- 扩展在安装、浏览器启动以及标签页创建、更新、切换、关闭时同步页面的 URL、标题和可用图标；在安装、浏览器启动、书签增删改移动以及书签批量导入完成时同步书签标题、网址和文件夹路径；不读取浏览历史、Cookie、表单或页面正文。
- `@网页` 菜单展示当前浏览器已打开的 HTTP(S) 网页，附件展示标题、域名、网址和可用的站点图标；用户确认后按普通网页资料保存，并进入元数据、自动分类和搜索流程。
- 用户点击扩展图标、使用快捷键或右键菜单时，仍可直接捕获当前标签页并打开 Web 快速捕获；这不会限制 `@` 选择其他已打开网页。
- Web 顶部和 `@网页` 未连接提示均提供扩展 ZIP 下载按钮；下载后展示解压并“加载已解压扩展”的安装说明。
- 未安装、未连接或尚未同步扩展时，`@网页` 显示下载、安装和连接指引，同时保留粘贴网址入口。
- 浏览器内部页、本地文件或不受支持协议不能收藏，界面应解释原因且不生成空资料。
- 打开书签导入窗口后优先自动读取扩展的最近书签快照；导入前展示书签总数、有效链接、重复链接和无法导入项，用户确认后再批量收藏。
- 导入时保留 Chrome 原文件夹路径用于来源追溯，但最终收藏分类由自动分类系统重新判断。
- 规范化网址相同的资料默认跳过，避免重复收藏；已有但尚未分类的资料可重新进入分类队列。
- 每个导入链接保存后立即可搜索，并在后台依次补充元数据、自动分类和自动标签。
- 导入页面展示总进度、成功数、跳过数与失败数；失败项可单独重试，并支持撤销本次新建内容。
- 后端异步读取合规的页面元数据：标题、站点、描述、封面。
- 收藏时不要求用户选择分类；系统根据网址、站点、标题和合规元数据自动分配一个主分类。
- 用户可以建立自己的分类模板，并为模板配置域名、网址或标题/描述关键词规则。
- 自动分类优先级为“用户规则 → 系统规则 → 大模型 → 其他”；用户规则命中后不再调用大模型。
- MVP 默认分类为：学习资料、文章阅读、视频与音频、工具与服务、书籍与论文、商品与好物、其他。
- 大模型可从系统分类和用户启用的自定义分类中选择，用户分类说明会作为分类提示上下文。
- 自动分类在后台执行，界面依次展示“分类中”、分类结果或“其他”，失败不能阻止资料保存。
- 大模型不可用、超时或输出不合法时自动降级到规则结果或“其他”，不得要求用户重新保存。
- Web 可修正明显错误的分类；修正只影响当前资料，并记录为后续分类规则评估样本。
- Web 可创建、停用和删除自定义分类规则；新规则会自动应用到已有的非人工覆盖资料。
- Android 只读展示自动分类，不提供分类修改入口。
- 每条网页资料只保留一个主分类，系统自动分配后允许用户在 Web 修正。
- 元数据获取失败不阻止保存，用户可在 Web 手动编辑标题与备注。
- 网页资料的用户可见组织属性仅为“分类 + 星标”；资源类型、阅读状态、标签、收藏夹和生命周期状态不作为资料表单字段或主列表筛选项。
- Web 网页资料不打开右侧编辑栏，分类下拉框和星标按钮直接放在最近内容列表中；标题和域名直接打开原网页。
- 详情页必须突出原始链接及域名，外链打开前保持可识别。

P1：选中文本随网页保存、跨设备书签增量同步。

### FR-04 灵感文字与语音记录（P0）

- 支持纯文字、纯语音、语音加文字三种记录方式。
- 录音界面显示录音时长、输入音量反馈、暂停、继续、完成和取消。
- 取消录音前必须二次确认；异常退出时尽量保留临时录音。
- 保存后上传原始录音，并创建异步转写任务。
- 转写中、成功、失败三种状态必须可见。
- 用户可以编辑转写文本，但原始录音不随文本编辑而变化。
- 转写失败时保留录音并允许重试。
- 录音前首次请求麦克风权限，并解释用途。

P1：从转写文本提取标题建议、语音自动分段。

### FR-05 资料库、搜索与筛选（P0）

- 全局搜索覆盖标题、正文、转写、单词、例句、标签和来源站点。
- 网页资料保存成功后必须立即进入搜索索引，不能等待自动分类或元数据任务完成。
- 网页资料搜索覆盖标题、原始网址、域名、页面描述、自动分类、自动标签和用户备注。
- 元数据与自动分类完成后应增量更新索引，使用户可以用内容主题而不只是网址找回资料。
- 网页资料支持按一个主分类和星标筛选；全局资料库仍可按内容类型切换。
- 支持按更新时间、创建时间、标题排序。
- 搜索结果明确展示内容类型和命中片段。
- 网页资料结果必须展示标题、站点、自动分类、命中摘要和“打开原链接”动作。
- Web 提供完整搜索与组合筛选；Android 使用同一资料数据进行搜索，并打开只读详情。
- Web 支持列表与卡片视图；Android MVP 使用信息密度适中的单列列表。
- 空状态说明原因，并提供新建或清除筛选入口。

### FR-06 详情与编辑（P0）

- 详情页先展示内容，再展示属性，避免表单感过强。
- 自动保存已确认的字段修改，并显示保存状态。
- Android 网页资料详情是只读例外：只提供浏览、复制和打开来源，不显示编辑表单。
- 删除进入回收站，默认保留 30 天；永久删除需要二次确认。
- 用户可修改类型。修改时保留通用字段，并提示无法映射的扩展字段。
- 每条内容可星标、归档、移动到回收站、复制链接。

### FR-07 回顾与再次使用（P0）

- 首页展示“今日回顾”，混合呈现到期单词、未读资料和待整理灵感。
- 每次回顾控制在 5 至 10 条，可单独跳过。
- 单词执行复习反馈；资料可打开原网页或切换星标；灵感可补充或归档。
- 回顾入口允许按类型进入专用队列。

P1：个性化回顾频率、每周摘要、随机漫游。

### FR-08 账号、同步与离线（P0）

- Web 与 Android 使用统一账号体系。
- Android 支持离线创建灵感、单词和录音；网页资料通过系统分享轻量保存，网络恢复后同步。
- 离线状态、等待同步、同步失败必须可见。
- 同一字段发生冲突时保留最近版本，并记录冲突日志；正文冲突应保留旧版本供恢复。
- 退出账号前提示仍未上传的录音和未同步内容。

### FR-09 导出、隐私与权限（P0）

- 用户可导出个人数据；MVP 至少支持 JSON，P1 支持 Markdown/CSV。
- 录音、转写和私人笔记默认仅本人可见。
- 麦克风权限仅在用户主动录音时请求。
- 网页元数据抓取不应携带用户登录态，不保存受限网页正文。
- 日志不得记录录音内容、完整转写、访问令牌或私人正文。

### FR-10 网页健康巡检（P0）

- 服务端按可配置周期自动检查所有未进入回收站且未暂停巡检的收藏网址，新收藏资料先完成一次初始检查。
- 巡检不携带用户 Cookie、登录态或访问令牌，只检查公开可访问的网址与最小元数据。
- 状态至少区分：正常、已重定向、内容信息有更新、需要登录、暂时失败、确认失效和已忽略。
- 单次超时、限流或服务器错误不能直接判定失效；只有跨多个检查周期连续失败才进入“失效候选”。
- HTTP 401/403 归为“需要登录或访问受限”，HTTP 429 和 5xx 归为“暂时失败”，不自动放入失效组。
- 永久重定向时提示用户将收藏更新到新网址，同时保留旧网址变更记录。
- 页面标题、描述或站点信息变化时提示“资料信息可更新”，用户确认后更新元数据和搜索索引。
- 确认失效的资料自动出现在 Web 的系统分组“失效网页”，但仍保留在资料库和搜索中。
- Web 提醒用户处理失效资料，并提供：重试检查、更新网址、忽略、移出失效组和移入回收站。
- 提醒采用站内汇总方式并合并同一站点故障，避免大量逐条通知。
- 系统不得自动永久删除资料；批量删除或清空失效组必须二次确认。
- 用户可为单条资料、站点或账号暂停巡检，并可调整提醒频率。
- Android 只读展示网页健康状态，不承担批量处理和网址更新。

## 7. 跨端分工

| 能力 | Web | Android |
| --- | --- | --- |
| 快速文字输入 | 完整支持 | 完整支持 |
| 网页资料创建与整理 | 完整创建；分类与星标在列表内直接修改 | 不提供常驻创建与已保存内容编辑 |
| 网页资料浏览 | 完整支持 | 核心体验，只读详情与打开原链接 |
| 网页资料自动分类 | 展示、筛选并允许纠正 | 只读展示分类结果 |
| Chrome 书签导入 | 核心体验，支持 HTML 批量导入 | 不提供 |
| `@网页` 当前浏览器网页选择 | 核心体验，通过 Chrome 扩展免复制收藏 | 不提供 |
| 网页健康巡检 | 提醒并处理失效、重定向和更新 | 只读展示状态 |
| 语音记录 | 支持浏览器能力；兼容性不足时给出提示 | 核心体验，支持后台上传 |
| 系统分享接收 | 不适用 | 核心体验，最小确认后保存为只读资料 |
| 批量整理 | 核心体验 | 基础支持 |
| 单词复习 | 完整支持 | 核心体验，适合碎片时间 |
| 离线创建 | P1，可用本地草稿 | P0 |

## 8. 非功能需求

- 性能：资料库首屏在常规网络下 2 秒内可交互；搜索输入后 300 毫秒内给出本地反馈。
- 可用性：核心捕获流程不因元数据、转写或词典服务失败而阻塞。
- 可访问性：文本对比度符合 WCAG AA；触控目标至少 44×44 dp；关键操作可使用键盘。
- 兼容性：Web 支持近两个主版本的 Chrome、Edge、Firefox、Safari；Android 最低版本在开发启动前根据用户覆盖率确认。
- 可观测性：记录捕获成功率、同步失败率、转写耗时和搜索延迟，不记录私人内容。
- 数据一致性：服务端为最终事实来源，客户端支持乐观更新和失败回滚。

## 9. 成功指标

- 新用户首日完成至少一次捕获的比例。
- 捕获流程完成率和中途退出率。
- 每周有至少一次“再次打开旧内容”的活跃用户比例。
- 搜索后打开结果的比例。
- 到期单词复习完成率。
- 语音转写成功率与 P95 完成时长。
- Android 分享保存成功率和跨端同步成功率。

指标只记录行为事件和技术状态，不上传用户正文、录音或搜索词原文。

## 10. MVP 发布验收

- 灵感和英语单词能在 Web 与 Android 创建、查看和编辑。
- 网页资料能在 Web 创建、查看和编辑；Android 能搜索、查看并打开原链接。
- Android 可从系统分享菜单轻量保存链接，保存后不提供资料编辑入口。
- 保存网页资料时无需手动选分类；元数据可用后系统自动归类，失败或低置信度时归入“其他”。
- 收藏完成后可立即通过标题、网址或备注搜索；后台任务完成后还可通过站点、描述和自动分类找到资料。
- Web 能通过新版扩展直接读取当前 Chrome/Edge 书签；重复链接不会重复创建，成功导入项立即可搜索并自动分类；未安装扩展时仍可使用 Chrome 书签 HTML。
- 启用扩展并打开多个普通 HTTP(S) 网页后，Web 输入 `@网页` 能列出当前浏览器的打开网页，选择任意一页完成收藏；整个流程不要求复制网址。
- 用户能从 Web 直接下载只包含运行文件的扩展 ZIP，解压后可在 Chrome 或 Edge 中加载。
- 连续巡检确认失效的网页会进入“失效网页”分组；用户可重试、更新、忽略或删除，系统不会自动永久删除。
- 语音记录在权限允许时可录制、播放、上传、转写和编辑转写。
- 全局搜索可以命中三类内容及语音转写。
- 到期单词能够完成一次完整的隐藏答案复习流程。
- 同一账号在 Web 与 Android 的数据最终一致。
- 服务失败和网络中断不会丢失尚未提交的文字或已完成的录音。
- 关键页面完成空、加载、失败、离线和无权限状态设计。

## 11. 待产品确认项

以下问题不阻塞当前设计，但应在进入开发迭代前确认：

- 首发账号方式：邮箱验证码、密码或第三方登录。
- 单词释义与发音的数据源及授权。
- 语音转写采用设备端、云服务还是自托管 PyTorch 模型。
- 免费用户的录音时长、存储容量和转写额度。
- 数据存储区域、备份周期与账号注销后的删除时限。
