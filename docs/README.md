# MemoIsle 文档索引

## 产品结论

英语单词、网页资料、灵感和图片可以放在一个产品中。它们的共同主线是：

> 捕获值得保留的内容 → 轻量整理 → 搜索或回顾 → 再次使用。

产品底层采用统一的 `Memo` 条目模型，上层按“单词、资料、灵感、图片”提供不同字段和使用方式。这样既能共享搜索、标签、收藏夹、同步与语音能力，也不会把不同内容强行做成完全相同的体验。

## 当前范围

- 阶段：MVP 内容类型（灵感、单词、资料、图片）、搜索、今日回顾与统一登录
- 平台：响应式 Web、Android 手机
- 目标输入分工：Web 完整支持各类内容；Android 支持灵感、单词、语音、系统分享保存资料及图片只读浏览
- 目标输出分工：跨端资料库、Web 资料编辑、Android 资料与图片只读浏览、单词复习和原始录音播放
- 下一阶段：见 [待办清单](backlog.md)，优先生产邮件验收、语音模型真实验收和生产部署验收
- 明确不包含：公开社区、复杂协作、完整网页离线存档、自动发布内容

## 需求变更规则

需求变更应先更新产品需求文档，再同步修改交互、技术和视觉文档，并更新 [待办清单](backlog.md)。涉及页面布局或视觉语言的变更，需要同时更新 Stitch 设计。
