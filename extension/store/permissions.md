# 权限用途说明（填写商店审核表单用）

**单一用途**：把用户正在浏览的网页、选中文本、网页图片、浏览器书签和浏览历史保存到用户自己的 MemoIsle 资料库。

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 用户点击扩展图标、右键菜单或快捷键时，读取当前标签页的网址和标题用于收藏。 |
| `scripting` | 仅在用户触发收藏时，在当前页执行一次脚本读取用户选中的文本（最多 10000 字），不读取未选中的正文。 |
| `tabs` | 读取各窗口已打开标签页的网址、标题和图标，同步给 MemoIsle，供用户在 MemoIsle 里输入 @ 选择要收藏的网页。只同步公网 HTTP(S) 页面，浏览器内部页、本地文件和内网地址会被过滤。 |
| `bookmarks` | 读取书签的标题、网址和文件夹路径，让用户在 MemoIsle 里直接预览并导入书签。扩展不会修改或删除书签。 |
| `history` | 读取浏览过的公网 HTTP(S) 网页的网址、标题、访问时间和访问次数，同步到 MemoIsle 的「浏览历史」，供用户搜索并一键收藏。扩展只读，不会修改或删除浏览器历史；未登录 MemoIsle 或退出登录后不再读取。 |
| `contextMenus` | 提供「收藏当前网页」和「收藏图片到 MemoIsle」两个右键菜单。 |
| `storage` | 在扩展本地保存 MemoIsle 的登录凭证和服务器地址。凭证不会写入网址。 |
| `notifications` | 收藏完成后显示结果通知，并提供「撤销」和「查看资料」按钮。 |
| `idle` | 只读取电脑处于「使用中 / 闲置 / 锁屏」哪种状态，用于把首次补全浏览历史这种耗时任务放到用户离开电脑时运行，避免占用正在使用的电脑。不读取任何键盘、鼠标或屏幕内容。 |
| `alarms` | 首次补全浏览历史尚未完成时，每 5 分钟唤醒一次扩展后台继续补全；补全完成后自动撤销闹钟。 |
| 主机权限 `<all_urls>` | 用户在任意网站的图片上右键选择「收藏图片到 MemoIsle」时，读取这张图片的字节并上传。扩展不用它读取页面内容、Cookie 或表单。 |
| 主机权限：MemoIsle API 地址 | 把收藏内容发送到用户自己的 MemoIsle 服务器。 |
| 内容脚本（只匹配 MemoIsle Web 地址） | 在 MemoIsle 页面上接收登录凭证，并告诉扩展该连接的 API 地址。不会注入其他网站。 |

**远程代码**：不使用。所有脚本都打包在扩展里，不加载远程脚本，也不执行 `eval`。

**数据使用**：扩展收集的网页地址、标题、选中文本、图片、书签和浏览历史只发送给用户自己配置的 MemoIsle 服务器，不出售、不转让给第三方，不用于广告或信用评估。浏览历史由扩展在本地读取后直接上报，不经过任何中间服务。
